# 🚦 Smart Traffic Congestion Prediction System

## 📌 Project Overview

The Smart Traffic Congestion Prediction System is a machine learning project designed to analyse traffic-related data and predict traffic congestion levels.

The project explores traffic patterns, identifies relationships between traffic conditions and congestion, and evaluates machine learning models for congestion prediction.

## 🎯 Problem Statement

Traffic congestion can increase travel time, fuel consumption, and commuter inconvenience. Analysing traffic-related data can help identify important factors associated with congestion and support the development of prediction systems.

## 🎯 Objectives

* Analyse traffic-related data using Python.
* Identify factors associated with traffic congestion.
* Visualise traffic patterns and relationships.
* Develop and evaluate machine learning models.
* Explore the development of a user-friendly prediction application.

## 🤖 Machine Learning

The project uses Random Forest Regression to estimate congestion levels from selected traffic-related features.

The models are evaluated using:

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)
* R² Score
